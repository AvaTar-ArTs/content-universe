# Continuation Layer

This directory restores the operational handoff layer recovered from `CreativeOS-ContentUniverse-Handoff-v3.0` after the canonical v5 forensic pack had already been assembled.

The recovered Handoff v3 is valuable because it contains a purpose-built continuation protocol, invariant registry, provider/backend taxonomy, use-case index, glossary and agent bootstrap prompt. Those pieces are operational guidance rather than merely historical narrative.

## Authority order

1. Current GitHub is authoritative for current `content-universe` code.
2. `../SOURCE_AUTHORITY_RULES_v5.md` governs cross-source conflicts.
3. Current captured repository snapshots govern adjacent repos such as Creator Camp and My Creators at their captured state.
4. Historical CreativeOS/iDeoMine handoffs remain authoritative for rationale and capabilities that never migrated, unless contradicted by newer verified code/evidence.
5. Unresolved links/captures remain unresolved evidence and must never be paraphrased from guesswork.
