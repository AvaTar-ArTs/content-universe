# Glossary

**Content Universe**  
Durable evidence, identity, provenance, lineage, recovery and query substrate.

**CreativeOS**  
Provider-neutral structured authoring and creative execution runtime.

**iDeoMine**  
Deep Ideogram-specific provider/workflow intelligence layer.

**Recovery Adapter**  
Parses existing evidence/history into normalized records.

**Provider Backend**  
Executes live or mock provider operations.

**Provider Dialect**  
Translates canonical structured intent to/from provider semantics.

**CreativeOperation / OperationRequest**  
Provider-neutral intended action such as generate/edit/remix/reframe/upscale.

**PromptLineage**  
History of the creator prompt, enhancements, provider dialect and provider autoprompts.

**SceneGraph**  
Typed structured scene with instances, geometry, text and references.

**StyleDNA**  
Portable representation of reusable style semantics.

**StyleStack**  
Ordered combination of style mechanisms.

**Reference Genome**  
Approved reusable creative canon/defaults/examples.

**StructuredDesignAsset**  
Creative artifact that includes structure, scene, prompt/style lineage and dependencies beyond a raster.

**ProviderJob**  
Asynchronous execution state tied to an operation.

**Provenance**  
Evidence of where a record/fact came from.

**Lineage**  
Parent/derivative/reference relationships between entities/assets/operations.

**Entity**  
Reusable canonical identity.

**Instance**  
One appearance/use of an entity in a scene/workflow.

**Memory MCP**  
Current Content Universe query/search/lineage/provenance surface.

**Action MCP**  
Future CreativeOS route/generate/transform/job/workflow surface.

**Model Fabric**  
Service exposing many underlying models/providers.

**Infrastructure MCP**  
Enabling MCP such as Playwright/Chrome DevTools, not itself a creative generator.
